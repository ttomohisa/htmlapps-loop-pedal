# Loop Pedal / ループペダル

4つのパッドに音を録音し、設定した小節数で自動的に繰り返して重ねられるブラウザツールです。机を叩く音、手拍子、声、ギターなどを組み合わせ、WAVとして保存できます。

> **開発プレビュー v0.2.0** — 音声エンジンと基本操作を実装した段階です。録音位置の実機校正、iPhone/Androidの音声経路テスト、リリース向けスクリーンショットは未完了です。正式リリースではありません。

## 機能

- 4つの独立したモノラルトラック。各トラックは現在のテイク1件を保持します。
- テンポ 40〜200 BPM、4/4拍子、1・2・4小節。最初は4拍のカウントイン、以降は次のループ境界から録音。
- 録音区間が終わると自動で再生に移り、トラック間のループ位相は共通の音声クロックで管理します。
- ミュート、個別音量、録音タイミング（−200〜+200ms）調整、録り直し、直前録音のUndo。
- ループ1回、30秒、60秒の16-bit mono WAVとして保存。ファイル名は編集できます。
- 日本語・英語を切り替えられます。録音音声はメモリ内だけに保持します。

## 使い方

1. HTTPSのページまたは対応ブラウザでHTMLを開き、録音方式とBPM・小節数を選びます。
2. 「マイクを使って録音」を押してマイクへのアクセスを許可します。ページを開いただけでは権限を要求しません。
3. 空のパッドを押します。4拍のカウント後、設定した小節数だけ自動的に録音されてループ再生が始まります。
4. 別の空のパッドを押すと、次のループ先頭から録音が始まります。録音済みのパッドはタップでミュートを切り替えます。
5. パッド右上の設定から録り直し・音量・タイミングを調整できます。「最後の録音を取り消す」も使えます。
6. 必要なら再生を停止し、ファイル名と長さを選んで「WAVを保存」を押します。

## 録音方式

**スマホだけで録音（初期値）:** 新しい音の録音中は、既存のループとクリック音を鳴らしません。再生音のマイクへの回り込みを減らす代わりに、録音中はほかの音を聴けません。

**イヤホンで重ね録り:** 録音中も別トラックの音を聴けます。有線イヤホンを推奨します。マイクの直接モニタリングはしません。Bluetoothの遅延を含む全端末での録音位置の一致は保証されません。

## データとプライバシー

マイク入力、トラックのPCM音声、WAV合成はブラウザ内で処理します。ユーザー音声の送信、クラウド保存、外部CDN、解析・テレメトリーはありません。配布HTMLには `connect-src 'none'` のCSPが適用されます。音声は自動永続化されず、ページの再読み込みや終了で失われます。

## 対応ブラウザと制約

AudioWorklet、Web Audio API、マイク使用権限、Blob URLを利用します。ブラウザとOSにより、HTTPSまたは安全なローカルコンテキストが必要です。単一HTMLを `file://` で開く動作、スマートフォン、イヤホン・Bluetooth・中断復帰は現在検証中です。音声がずれる場合はパッドの録音位置を調整してください。

本アプリは高度なDAWではありません。オーバーダブの多段履歴、素材の読み込み、エフェクト、セッションの自動保存はありません。実機での遅延・継ぎ目・回り込みは正式リリース前に検証します。

## 開発・ビルド

このリポジトリは [htmlapps-template](https://github.com/ttomohisa/htmlapps-template) の現行構成に従います。ソースは `src/index.template.html` に保持し、生成された `dist/index.html` などは手動で編集しません。

Windowsでは `build-standalone.bat`、または PowerShellで `./scripts/check-repository.ps1` を実行します。通常のビルドでは以下を生成します。

- `dist/index.html` — 通常の単一HTML
- `dist/index.self-extract.html` — gzip自己展開版
- `loop-pedal.html` — リポジトリ直下の通常版コピー（ビルドで生成）
- `dist/build-size-report.json` — ビルドサイズ情報

音声クロックの自動テストには Node.js を用い、`node --test tests/loop-pedal.test.cjs` を実行します。GitHub Actionsでも同じテストとテンプレートの検証を実行します。
